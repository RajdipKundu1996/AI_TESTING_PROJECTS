* Midnight
* Ocean Deep
* Forest Dark
* Carbon Black

# Default Theme

Set:

```text
eMudhra Enterprise
```

as platform default.

Reason:

* Matches branding.
* Professional appearance.
* Highest acceptance among enterprise users.
* Works well with dashboards, tables, forms, and reports.

---

# Final Requirement

Every theme must:

✓ Pass WCAG AA

✓ Have unique visual identity

✓ Update all UI components

✓ Support tables

✓ Support forms

✓ Support charts

✓ Support dashboards

✓ Support AI modules

✓ Support Admin Command Center

✓ Support mobile responsiveness

No two themes should look visually similar.
