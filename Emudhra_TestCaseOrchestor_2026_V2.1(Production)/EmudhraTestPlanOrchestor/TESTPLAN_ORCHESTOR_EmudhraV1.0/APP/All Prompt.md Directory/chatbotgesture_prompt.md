# QA Assistant Mascot Prompt

## Master Character Design Prompt

Create a premium mascot character for an AI QA (Quality Assurance) Assistant chatbot.

A tiny chibi-style human assistant with subtle robotic elements, designed to become the recognizable face of a professional AI chatbot platform.

- Gender-neutral cute assistant (can appear as boy or girl)
- Age appearance: 8–12 years old chibi proportions
- Head-to-body ratio: 70% head, 30% body
- Friendly, intelligent, trustworthy
- Designed specifically for conversations, testing, QA, support, guidance, and problem solving
- Must feel approachable, smart, and emotionally warm
